# Project workflow

- Before starting a task, pull the latest code from `origin` (https://github.com/daudibrahimhasan/choloCampus). Use a normal pull that preserves local work; do not reset, discard uncommitted edits, or force-push. Resolve divergence safely before proceeding.
- After completing a task, run the appropriate checks, commit the completed changes, and push to GitHub. Report the pushed commit. If authentication or permissions block synchronization, explain the exact blocker.
- Keep credentials, local environment files, generated builds, signing keys, and downloaded build tools out of Git.
